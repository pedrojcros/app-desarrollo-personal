# Tipografías

Instancias estáticas, recortadas a latín, de las fuentes variables de Google Fonts (licencia SIL OFL 1.1; el texto de cada licencia está en `OFL-*.txt`).

| Tema          | Fuentes                    | Ficheros                       |
| ------------- | -------------------------- | ------------------------------ |
| Blanco        | Fraunces (títulos) e Inter | `Fraunces-SemiBold`, `Inter-*` |
| Negro         | DM Sans                    | `DMSans-*`                     |
| Tercer estilo | Archivo                    | `Archivo-*`                    |

Se cargan en `src/theme/fonts.ts`. Se generaron con `fontTools` (`instancer` y `subset`) a partir de las fuentes variables oficiales.
